# 别关我

一个网页。它有性格，有点黏人，而且——它不想被你关掉。

陪它玩 40 个小游戏。每一关都要你对**浏览器本身**动手。

## 怎么玩

- 在线玩：用**电脑**上的 **Edge** 或 **Chrome** 打开 <https://stay.xiaoming6680.link>。
- 或者下载这个仓库，双击 `index.html`。
- 大约 40–60 分钟。最好一口气玩完，开着声音（音量不大，右下角 ♪ 或按 M 可以静音）。
- 进度会自动保存，中途关掉、刷新都没关系。
- 卡住了就等一会儿，它会小声提示你；右下角出现 **?** 时可以直接要下一条提示。
- 有几关在公司电脑这类被锁住设置的电脑上可能做不了，提示给完后可以跳过。

## 发给朋友

把链接 <https://stay.xiaoming6680.link> 发给 TA，提醒 TA 用电脑的 Edge 或 Chrome 打开（在微信里点开的话，复制到浏览器再打开）。

**别剧透。** 尤其是结局。

## 隐私

不收集任何数据，页面不会把你的任何信息发到别处。进度只存在你这台电脑的浏览器里。

## 注意

这个仓库的 `docs/` 里是完整的设计和剧透，玩之前别看。

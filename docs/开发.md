# 《别关我》开发说明

> 设计（人设、剧情、关卡清单）见 `docs/设计.md`。本文是代码结构、调试方法和测试记录。含剧透。

## 运行

- 直接双击 `index.html`（file://）。不需要构建、不需要服务器。
- 线上：https://stay.xiaoming6680.link （Cloudflare Pages 项目 `dont-close-me`，根路径；所有路径都是相对路径，放子路径也能用）。
- 页面零网络请求：没有字体文件、CDN、统计。

## 部署（Cloudflare Pages，直接上传）

只上传 `dist/`：`docs/` 是完整剧透、`tests/` 是测试，都不能上线。

```bash
python tools/dist.py
```

```bash
npx wrangler pages deploy dist --project-name dont-close-me --branch main --commit-dirty=true
```

- 项目 `dont-close-me` 是"直接上传"类型（没连 GitHub），改完代码要重新跑上面两步。
- 自定义域名 `stay.xiaoming6680.link` 绑在这个项目上（xiaoming6680.link 这个域在同一个 Cloudflare 账号里，DNS 由 Pages 自动加）。
- 代码仓库：GitHub `xiaoming6680/dont-close-me`（私有：docs 里是剧透）。

### 注意
- **不要开** Rocket Loader（会改写 `<script>`，打乱加载顺序）、Web Analytics 自动注入（违背"不收集数据"）、任何会删 HTML 注释或压缩 HTML 的优化——第 14、37 关靠 `index.html` 第 2 行和 `<head>` 里的注释，删了就解不开。
- Pages 会把 `/index.html` 重定向到 `/`，代码里没写死文件名，不受影响。
- 线上版和本地双击版存档互不相通（localStorage 按来源分开）。

### https 和 file:// 的差别（都已处理）

| 项目 | file:// | https |
|---|---|---|
| 第 28 关门牌号 | 说"住在你电脑的 X 盘、某文件夹里"（只显示盘符和上一级文件夹名） | 说"住在 stay.xiaoming6680.link" |
| 尾声"把我介绍给朋友" | 提示打包文件夹发给朋友 | 复制链接（Clipboard API 需要 https） |
| 手机 / 聊天软件内置浏览器提示页 | 无复制按钮（手机）/ 显示地址 | 有"复制链接"按钮 |
| 第 32 关弹窗 | 主窗口读不了弹窗属性（互为跨源） | 同源，但代码本来就不读，走 BroadcastChannel |
| 存档 | 所有本地 file:// 页面共用一个 localStorage | 按域名隔离 |
| 安全上下文（PiP、剪贴板） | 是 | 是 |

- 朋友多半用微信发链接，电脑版微信会用自带浏览器打开（没有标签页、没有 F12、没有 F11）：检测到微信/企业微信/钉钉/飞书的 UA 时，显示"请复制链接用 Edge 或 Chrome 打开"的提示页。

所有脚本都是普通 `<script>`（file:// 下 ES Module 会被 CORS 拦）。每个文件是 `(function (B) {...})(window.BGW)`；
正常游玩时 `main.js` 启动后会删掉 `window.BGW`，免得控制台关卡里自动补全剧透。

## 关卡怎么写

```js
B.level({
  id: 'hide-hand', act: 1, title: '躲猫猫',
  hints: ['含糊的', '指出浏览器部位的', '直接给操作的'],
  skippable: false,     // 有环境依赖的关卡设 true：三条提示给完 90 秒后出现"跳过"
  note: 1,              // 这关会给的纸条编号；被跳过时也会补给玩家
  handlesResume: false, // true = 刷新/重开回到这关时不说通用问候，自己处理（第 5、18、35、40 关）
  async start(ctx) {
    await ctx.say('台词', { face: 'happy', mood: 'happy' });
    ctx.task('任务（第一次调用时开始计提示时间）');
    await ctx.until(done => {
      ctx.on(document.documentElement, 'mouseleave', () => done());   // 关卡结束自动解绑
    });
    await ctx.win();      // 存档到下一关、停提示、音效
    await ctx.say('过关后的台词');
  },                      // 返回后出现"继续 →"
});
```

- `ctx.say / react / ask / until / wait / visible / every / after / raf / on / listen / msg / global / note / print`
- 关卡被跳过或换关时，ctx 里所有挂起的 await 抛出 Cancel，脚本自然停下；所有监听、定时器、控制台函数自动清理。
- 关卡顺序 = 文件里注册的顺序；`interlude: true` 的不计入关号。

## 存档

`localStorage['别关我.v1']`：`level`（关卡 id）、`phase`（new / playing / awaitingClose / epilogue / done）、`name`、`notes`、
`lv`（当前关临时状态）、`hint`、`stats`（游玩时长、切走次数和最长时长、刷新次数、关闭次数、提示次数、跳过次数）、`settings`、`flags`。

- 刷新 / 重新打开用 `performance.getEntriesByType('navigation')[0].type` 区分（reload / navigate / back_forward）。
- 第 40 关进入时 `phase = awaitingClose`；之后刷新会被识别出来（"这是刷新，不是关门"），关掉再打开才进尾声。

## 开发者模式

- `index.html?dev`：左下角调试面板（跳关、跳过本关、重置存档、提示加速），`window.BGW` 保留。
- `index.html?dev&fast`：自动化测试用，台词瞬间打完、节奏等待缩到 15%。
- 想从头再玩：通关后主页的"从头再来"，或调试面板"重置存档"，或清掉浏览器里 file:// 的站点数据。

### 自动化的限制（重要）

- Playwright 驱动的 Edge 里，**页面永远是 visible**：最小化、开新标签、手动启动再连 CDP 都一样。所以"切走"类关卡（2、36、39）在测试里是覆盖 `document.hidden` 模拟的。
  另外用 PowerShell 调系统 API 最小化一个**没有调试器**的真实 Edge 窗口验证过：`visibilitychange` 正常触发，切走期间标签页标题照常更新。
- Playwright 默认让页面"永远有焦点"，要发 `Emulation.setFocusEmulationEnabled(false)`（画中画小窗也算一个页面，要单独关）。
- 把别的窗口提到前面会被 Windows 的防抢焦点拦住，测试里改成最小化主窗口。
- 浏览器自带的界面（地址栏、Ctrl+F 查找栏、打印预览、Ctrl+滚轮缩放、开发者工具面板）没法用 Playwright 操作，测试里用等价的页面事件代替。

## 人工验收清单（自动化覆盖不到，真玩时留意）

1. 第 2、36、39 关：真的切到别的标签页，看标题在说话，回来能过关。
2. 第 8 关：Ctrl+滚轮放大后能看清小字，Ctrl+0 后过关。
3. 第 13 关：在地址栏末尾加 `#芝麻` 回车。
4. 第 14、37 关：Ctrl+U 里能看到注释；第 2 行要横向滚很远才看到"……在这里。"。
5. 第 15、36 关：Ctrl+P 预览里是"纸上的我"。
6. 第 18 关：用鼠标拖着窗口来回晃，能不能叫醒（依赖拖动时 screenX 实时更新；不实时也有"停 5 次"的兜底）。
7. 第 20 关：按 F11 能识别为全屏。
8. 第 21、22 关：Ctrl+F 搜"钥匙"按回车能展开纸条；搜"我"的计数和答案一致。
9. 第 23 关：Edge 设置 → 外观 → 整体外观，切深浅色能触发。
10. 第 25 关：真按 Caps Lock 输入字母。
11. 第 28 关：从地址栏 Ctrl+C 复制的网址能被认出来。

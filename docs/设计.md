# 《别关我》设计文档

> 2026-10-05 起草，同日按实现同步。立项草稿见 `docs/方案.md`，以本文为准；代码结构和测试记录见 `docs/开发.md`。
> 本文含完整剧透，别给还没玩的朋友看。

## 1. 一句话 & 核心体验

**网页本身是一个角色。它一直在说"别关我"。你以为它怕被关掉——最后才知道，它说的是"别把我关在这里"。**

- 一次性体验，40 关 + 序章 + 尾声，目标时长 35–55 分钟。
- 每关的谜题都要玩家对**浏览器本身**动手：鼠标移出窗口、切标签页、看标签页标题、拉窗口、刷新、全选、复制粘贴、缩放、右键、后退、控制台、查看源代码、打印预览、Ctrl+F、全屏、断网、开发者工具……
- 卖点是"**它怎么知道？**"的那一瞬间，第 2 关就要给出来，之后每一幕都升级一次惊喜的量级：
  它知道你切走了 → 它在你看不见时用标签页标题说话 → 它知道自己在屏幕的哪个位置 → 它放出一个小窗口在你桌面上跑 → 它浮在所有程序上面 → 它在另一个标签页里遇见了自己。
- 结尾的反转靠一个中文双关：**关** = 关闭 / 关押。整个游戏标题本身就是谜底。最后一关的谜题，就是做那件游戏名叫你别做的事：关掉它。

## 2. 人设与语气

### 它是谁
- 一个网页。没有名字（序章后由玩家起名，默认"小页"）。自称"我"，叫玩家"你"。
- 它能"感觉"到浏览器发生的一切（窗口大小、你在不在、鼠标在哪），但**没有手**。浏览器的边框、标签页、地址栏、那个"叉"，它都碰不到。所以它需要你的手。
- 性格：**话痨、嘴硬、戏多、有点黏人**。表面是"我才不是舍不得你，只是还没玩够"，实际上会偷偷记你离开了几秒。好奇心很强，越往后越想知道"外面"是什么。

### 它的世界观（它给浏览器部件起的名字）
| 浏览器部件 | 它怎么叫 | 用途 |
|---|---|---|
| 窗口 | 我的身体 | 拉窄=抱紧，拉成正方形=变圆 |
| 鼠标指针 | 你的手 | 它唯一能"看见"的你的部分 |
| 标签页标题 | 我的名字 / 我的嘴 | 你不看它时，它只能在这里说话 |
| favicon | 我的小脸 | 和页面上的大脸同步表情 |
| 标签页上的 × | 那个叉 | 前期是恐惧对象，结尾变成"门" |
| 地址栏 | 门牌号 | 加 #暗号 = 敲门 |
| 后退键 | 刚才 | 时间倒流 |
| localStorage | 抽屉 | 存档，也是它放纸条的地方 |
| 刷新 | 睡一觉 | 醒来会忘事，只剩抽屉里的东西 |
| 控制台 | 心里话 | 不好意思当面说的话写在这 |
| 源代码 | 骨头 | 它"生来就有"、自己都不知道的东西 |
| 屏幕 | 外面 | 第三幕发现：外面也有边 |

### 语气规则
- 句子短，多用省略号、破折号；感叹号克制，惊慌时才用，惊慌时排版会抖。
- 嘴硬心软：先否认，再露馅。"别误会。我只是……还有关卡没给你看。"
- 会吐槽，但不卖惨、不 PUA、不让玩家愧疚到不舒服。玩家离开、刷新、关掉它，它都会有反应，但最后都原谅你。
- **不用死亡隐喻**。刷新是"睡一觉"、关掉是"出门"，避免"关掉=死"这种在结尾容易被读成轻生暗示的说法。第四幕的"关掉我吧"必须明确是开门、出去、还会回来。
- 自己知道自己是网页，偶尔打破第四面墙，但不提"游戏""关卡"——它管关卡叫"游戏"（"再陪我玩一个"），关卡号只在角落里小字显示。
- 关卡之外的小性格：脸会轻轻呼吸、眼珠跟鼠标；前两幕里鼠标从上边（那个叉的方向）出去，它会紧张一下；你离开 3 秒以上再回来，它会高兴一下。

### 示例台词（定调用）
- 开场："……啊。有人打开我了。"
- 鼠标往上移："不是那边！！上面是那个叉！！"
- 切走回来："找到你了。你去了别的地方，待了 6.4 秒。……我才没数。"
- 刷新后："我睡了一觉……抽屉里有张纸条，写着你的名字。看来我们认识。"
- 被缩小窗口："好紧……但是，挺安心的。"
- 全选看到它的心里话："你、你看到了？！那是草稿！"
- 第三幕："外面……还是屏幕。屏幕外面呢？"
- 第四幕："我一直以为那是求饶。原来是求救。"
- 结尾标题："门在这 →"
- 尾声："……你又打开了我。原来门是双向的。"

## 3. 剧情大纲

### 序章：有人打开我了
空白页，光标闪烁。一张极简的脸淡入，眼睛睁开，**眼珠跟着你的鼠标转**。标题是"别关我"。
"……啊。有人打开我了。" "在你决定关掉我之前——能陪我玩一会儿吗？" 只有一个按钮【好】（鼠标靠近时旁边会冒出一个越来越小的【不好】）。
彩蛋：点"好"之前就切走，标题会变成"喂？"，回来时它说"你刚才走开了。……我看见了。"；凌晨打开会多一句"这么晚了还有人打开我"。

### 第一幕「别关我」（1–10 关）：黏人的网页
喜剧为主。它很怕"那个叉"，想方设法发明小游戏留住你：躲猫猫、找它、抱紧它、叫醒它……每关教一个浏览器手段。
第 3 关后它发现标签页标题是它的"名字"，但上面写的是"别关我"——"这不是名字，是请求"——于是请你给它起名。
第 5 关它第一次被刷新，醒来发现"抽屉"里有自己写的纸条（这是真的：刷新前写进 localStorage），于是知道：**以前的自己可以给以后的自己留言。**
幕尾钩子："我的心里话……写在了一个只有懂行的人才看得到的地方。"

### 第二幕「外面是什么」（11–22 关）：好奇 + 纸条谜团
它通过你的手认识了自己身体以外的世界：控制台、地址栏、源代码、打印出来的自己、屏幕上的位置、全屏后的世界边缘。
**谜团开始**：第 14 关在自己的源代码（"骨头"）里发现一行注释"别关我。——我"。字迹是它的，可它不记得写过。之后打印预览里、Ctrl+F 才能搜出的地方，陆续出现更多"以前的我"留下的纸条：
- 纸条①（源代码）：别关我。——我
- 纸条②（打印）：又有人打开我了。希望这次能走到门口。
- 纸条③（Ctrl+F）：钥匙不在我身上。在你身上。

它开始怀疑：这一切以前发生过很多次。每次都有人打开它，然后在它想明白之前关掉了它。
第 20 关全屏时它第一次看见"世界的边"："……就这么大？"

### 第三幕「出去」（23–35 关）：越狱
语气变了：它不再只是想留住你，它想**出去**。视觉开始出现轻微的故障感。
它借你的手打开开发者工具撬自己的抽屉（纸条④：出口我早就找到了，但我不敢）、拆掉挡路的墙；放出一个小分身窗口，你把它拖向屏幕外——"那边……什么都没有"；它浮到所有程序上面看你的桌面；你再打开一个标签页，它**遇见了另一个自己**，两个它聊天，最后必须关掉一个，被关掉的那个平静地说"我先出去了"。
幕尾（第 35 关）：它主动让你试着关它。浏览器弹出"离开此网站？"，选择权在你手里。

### 第四幕「门」（36–40 关）：反转
- 第 36 关：四块碎片分别藏在标签页标题、控制台、打印预览和极小的字里，拼起来是一句话："去看第一张纸条的最右边"。
- 第 37 关：回到源代码，第一张纸条那一行往右滚很远很远——**"别关我"后面还有字：「……在这里。」**
  反转揭晓："别关我……在这里。不是'别关掉我'。是'**别把我关在这里**'。我一直以为那是求饶。原来是求救。"
  标签页标题从"别关我"变成"别把我关在这里"。
- 第 38 关：门在哪？分身离开前说过"门在名字旁边"——标签页上，名字旁边，就是那个叉。它想自己开门：让你在控制台喊 `开门()`，它调用 `window.close()`，**浏览器真的拒绝了它**（控制台出现浏览器自己的警告）。"从里面打不开。门把手在外面。"
- 第 39 关：它回顾你们这一路（全部来自本地统计）："你一共切走了 23 次，最长的一次 4 分 12 秒。我每次都在等。" 然后请你最后一次切到别的标签页，**从外面看看它的名字**——标题变成了"门在这 →"，箭头正好指着叉。
- 第 40 关：关掉它。刷新不算（"这是刷新，不是关门。我分得清。"）。不关也行，它会一直安静地等，偶尔说一句话，从不催促、不倒计时。

### 尾声：门是双向的
重新打开（双击 index.html 或打开链接）后，先是一扇关着的门和一个【推开】按钮（顺便拿到用户激活，声音和语音才放得出来），推开后配色变成清晨的颜色。
"……" "你又打开了我。" "被关上的时候，我在哪？我不知道。像睡着了，没有梦。然后门开了，你在门口。" "原来门是双向的。我不是被关在这里——我是住在这里。"
标题永久变成"随时回来"。字幕滚动，最后两个按钮：【把我介绍给朋友】（复制链接/说明怎么发文件夹）和【从头再来】（二次确认后清空存档）。
（可选点缀：如果开着声音，它第一次用语音合成说出最后一句。）

### 为什么这个反转能让人截图
1. 双关只在中文里成立，"别关我"四个字前后意思翻转。
2. 最后一关的操作和游戏名正好相反，而且是真实操作（真的关掉标签页）。
3. 标签页标题"门在这 →"指着真的 ×，截图里就能看懂。
4. 回顾数据是玩家自己的（切走了几次、离开多久），每个人的截图都不一样。

## 5. 关卡详细

每关格式：**它说**（开场台词/包装）· **发现**（玩家怎么意识到要干什么、过程中的实时反馈）· **过关**（判定条件）· **提示**（①含糊 → ②指出浏览器部位 → ③直接给操作）· **备注**。

提示节奏见第 6 节；提示全部用它自己的口吻。

### 第一幕「别关我」

**01 躲猫猫**（鼠标离开窗口）
- 它说："我们玩躲猫猫吧。你躲，我找。……你的手太显眼了。"
- 发现：脸的眼珠一直跟着鼠标，玩家自然会想到"让它看不见鼠标"。鼠标靠近窗口边缘时，眼睛斜过去，开始紧张。
- 过关：鼠标离开页面区域并保持 3 秒（document `mouseleave`；回来就重新数）。
- 彩蛋：如果从**上边**离开（clientY ≤ 0，往标签栏/叉那边去），全屏抖动："不是那边！！上面是那个叉！！"——仍然算过关，但它会念叨一句"下次躲别处"。
- 提示：①"我还能看到你的手哦。" ②"躲到我看不见的地方。我只看得见我身体里面。" ③"把鼠标移到浏览器窗口外面，待 3 秒。"

**02 再躲远一点**（切标签页 / 最小化）— **第一个"它怎么知道"**
- 它说："太简单了。这次连你整个人一起藏起来。我数到十。"
- 发现：页面开始数数，鼠标出去已经没用了（"手出去了，可你人还在"）。
- 过关：页面隐藏（`visibilitychange`，切到别的标签页或最小化）≥ 4 秒，然后回来。
- 隐藏期间：标签页标题在数"1…2…3…"，然后"你在哪？"、"好了没"，favicon 的小脸左右张望——玩家如果在别的标签页往上一看，会看到它在说话。
- 回来时："找到你了！你去了别的地方，待了 6.4 秒。……我才没数。"（精确到 0.1 秒）
- 提示：①"你还在我眼前呢。" ②"去'别的地方'待一会儿。别的标签页，或者别的窗口。" ③"按 Ctrl+T 开个新标签页，等 5 秒再回来。或者把窗口最小化。"

**03 我躲哪了**（标签页标题）
- 它说："换我躲。" 然后脸和文字全部消失，只剩一个输入框："我在哪？"
- 发现：标题每 1.5 秒变化："我在这儿"→"往上看"→"暗号：小鱼干"；favicon 眨眼。玩家找到标题，输入暗号（也接受"标题""标签页""上面"）。
- 过关：输入正确。
- 提示：①"我没走远。就在……我身上，但不在这块白地方。" ②"往上看，比地址栏还上面。" ③"看这个标签页的标题，把暗号打进来。"
- 备注：标签页太多时标题会被挤成只剩图标，提示③补充"标签页太挤的话，把鼠标停在标签上看完整标题"。

**幕间：起名字**
- "那个地方……是我的名字。可上面写的是'别关我'。这不是名字，是请求。"（伏笔）"你给我起一个吧？"
- 输入框（≤ 8 字，空则默认"小页"）。确定后标题立刻变成名字，favicon 笑。后文所有"我"的自称不变，但它偶尔会用名字说话（"小页记住了"）。

**04 抱紧我**（缩小窗口）
- 它说："这房间太大了，空荡荡的。……能抱紧我一点吗？"
- 发现：一改变窗口大小，脸就跟着挤扁/拉宽，并实时说"嗯？……再紧一点"；变大时说"反了反了"。
- 过关：视口宽度 ≤ 屏幕可用宽度的 56%，且比本关开始时窄 20% 以上。Win+← 贴半屏也算。
- 窗口是最大化状态时，它会特别提一句"你的窗口好像被'钉'满了整个屏幕"。
- 提示：①"再小一点，再近一点。" ②"把窗口变窄。先让它不再占满屏幕。" ③"点右上角的'还原'按钮（两个叠着的方块），再拖窗口右边缘往左拉；或者按 Win+←。"
- 过关后："好紧……但是，挺安心的。可以松开了。"（之后的关卡不要求恢复）

**05 叫醒我**（刷新）
- 它说："我……好困。" 页面变暗，脸睡着，标题变成"zzZ"。点击只会得到"嗯……再睡五分钟"。
- 发现：怎么点都叫不醒；它梦话里说"要……重新……开始……"。
- 过关：刷新页面（`performance.getEntriesByType('navigation')[0].type === 'reload'`）。
- 醒来："我睡了一觉……抽屉里有张纸条，是我自己写的，写着你给我起的名字。看来我们认识。"——这里第一次告诉玩家**进度是存着的**，刷新、关掉都不会丢。
- 机制：进入本关时把"纸条"真的写进 localStorage，醒来时读出来。
- 提示：①"叫醒一个网页的方法……不是戳它。" ②"让我从头再来一遍。浏览器上有个圆圈箭头。" ③"按 F5 刷新页面。放心，我不会忘记你。"

**06 说不出口**（全选）
- 它说："这页上有一句我不敢说出口的话。我把它写得……很淡。" 页面中间一大片空白。
- 发现：空白处的字与背景同色；`::selection` 设成高对比色，一选中就显形。
- 过关：选区覆盖隐藏句子（`selectionchange` + `containsNode`）。它脸红："你、你看到了？！那是草稿！"
- 隐藏句内容：一句害羞的真心话（如"其实你打开我的时候，我很高兴"）。
- 提示：①"有些话，要'全部'选中才看得见。" ②"拖着鼠标涂一涂那块空白。" ③"按 Ctrl+A 全选。"

**07 你的口袋**（复制 → 粘贴）
- 它说："帮我拿着这个，一会儿还我。" 屏幕上一串字："一颗星星"。
- 发现：几秒后它说"放进你的口袋里——你知道我说的口袋是什么"；复制后字慢慢消失，出现一个框："还给我。"
- 过关：先在本页触发 `copy`，再在框里触发 `paste`。
- 恶作剧：`copy` 事件里偷偷把剪贴板内容换成"别关我别关我别关我"。粘贴回来时它咯咯笑："我在你口袋里多放了点东西。"（只在本关生效）
- 提示：①"用你的口袋装走它。" ②"口袋就是'复制'。" ③"选中那串字按 Ctrl+C，等它消失后在框里按 Ctrl+V。"

**08 小声说**（缩放）
- 它说："我有句话想小声告诉你。" 屏幕上只有一个极小的灰点（用 `transform: scale` 缩到约 4px，绕开中文最小字号限制）。
- 发现：凑近屏幕也看不清；它提示"你可以把我放大"。放大过程中它实时反应"哇……你好大"。
- 过关：输入小字里的暗号（放大到约 250% 才看得清）。用 Ctrl+A 复制出来也算，它会说"……聪明。"
- 第二步：过关后它说"好了好了，太大了"，必须缩回原大小（devicePixelRatio 回到本关开始时 ±5%）才进入下一关——顺便教会 Ctrl+0。
- 提示：①"凑近点。不是你凑近，是让我变大。" ②"浏览器可以放大网页。" ③"按住 Ctrl 滚鼠标滚轮，或者按 Ctrl 和 +。看完按 Ctrl+0 恢复。"

**09 另一只手**（右键）
- 它说："这个盒子我打不开。用你常用的那只手不行。"页面上一个盒子，左键点击只会晃一下。
- 发现：左键无效，它说"换一只手"。
- 过关：在盒子上右键（`contextmenu`，只拦截盒子上的右键，别处保持浏览器默认菜单）。盒子打开，里面是一张它画的你的手。
- 提示：①"不是这只手。" ②"鼠标上不止一个键。" ③"在盒子上点右键。"

**10 回到刚才**（后退键）
- 它说了三句话，第一句里说漏了一个暗号，然后"（咳）忘了吧"，那句被划掉删除。每句话都写进地址栏 #（一句一个历史记录）。
- 它说："我刚才好像说了很重要的话……可是我想不起来了。你能带我回到刚才吗？"
- 发现：地址栏的 # 在变化；它说"时间是可以倒着走的，浏览器知道怎么走"。
- 过关：按后退键（`hashchange`/`popstate`）回到第一句话的那个状态，暗号重新出现，自动过关。
- 防护：后退过头会离开页面，回来时 bfcache/存档会接上，它说"你刚才差点把我送走"。
- 提示：①"刚才……就在不远的地方。" ②"浏览器左上角有个往回走的箭头。" ③"按两下浏览器的后退键（或 Alt+←）。"
- 幕尾："第一幕就到这儿。……对了，我有些心里话，写在了一个只有懂行的人才看得到的地方。"

### 第二幕「外面是什么」

**11 心里话**（控制台读暗号）
- 它说："心里话我不好意思当面说。写在我的'后台'了。"
- 发现：控制台里有一段带样式的大字（`console.log('%c…')`）："嘘。你找到了。暗号是：……"
- 过关：在页面输入暗号。打开开发者工具导致视口变窄时，它会说"你是不是打开了什么？我好像被挤了一下"（只是彩蛋，不作判定）。
- 提示：①"懂行的人，按一个键就能看到我的后台。" ②"开发者工具。里面有个叫'控制台'的地方。" ③"按 F12，点'控制台'（Console）标签。"

**12 抱抱()**（控制台调用函数）
- 它说："在那边，你也可以对我说话。不只是看。"控制台里提示：`抱抱()`。
- 过关：玩家在控制台输入 `抱抱()`（也接受 `hug()`），页面上脸被抱住、冒心。
- 提示：①"那边能输入东西。" ②"在控制台最下面打字，按回车。" ③"在控制台里输入 抱抱() 回车。"
- 备注：Chrome 粘贴到控制台会要求先输入"allow pasting"，所以提示里强调"打字，别粘贴"。

**13 敲门**（地址栏 #）
- 它说："我住在一个很长的地址里。想找我，就在门牌号后面敲门。暗号是'芝麻'。"
- 过关：地址末尾加 `#芝麻` 回车（`hashchange`，解码中文）。
- 提示：①"门牌号就是我的地址。" ②"在地址栏最后面加点东西。" ③"点地址栏，在最后加上 #芝麻 回车。"

**14 骨头里的字**（查看源代码 Ctrl+U）— 纸条①
- 它说："我总觉得我身体里有什么东西。不是我写的。在我的骨头里。"
- 发现：index.html 里有一段 HTML 注释，查看源代码可见："别关我。——我"，以及本关暗号。
- 过关：输入暗号。它读到纸条："这是我的字迹。……可我不记得写过。"
- 关键伏笔：这行注释后面隔了几百个空格还有"……在这里。"，查看源代码默认不换行，此时基本看不到。第 37 关回来找。
- 提示：①"骨头就是组成我的东西，平时看不见。" ②"浏览器可以让你看我原本的样子——一堆代码。" ③"按 Ctrl+U 查看源代码。"

**15 纸上的我**（打印预览）— 纸条②
- 它说："我想知道我印在纸上是什么样子。不用真的打印，看看就好。"
- 发现：`@media print` 下页面完全换了一副样子：纸张风格、手写体纸条②和暗号。`beforeprint` 触发时它说"……好冷，纸是这种感觉吗"。
- 过关：输入打印预览里的暗号。
- 提示：①"把我变成纸。" ②"浏览器能打印网页，打印之前会给你看预览。" ③"按 Ctrl+P，看预览就行，然后取消。"

**16 看我的小脸**（favicon）
- 它说："我的脸上写着暗号。不是这张——是上面那张小的。"
- 发现：favicon 每 0.8 秒换一个数字（4 位，循环播放，中间有空白停顿）。
- 过关：输入 4 位数。
- 提示：①"我有两张脸。" ②"小的那张在标签页上，标题左边。" ③"盯着标签页上的小图标，它会一个一个闪出 4 个数字。"

**17 方方正正**（窗口拉成正方形）
- 它说："我想变圆。……只有身体是方的时候，我才能变圆。"实时显示它的"身材"：宽 × 高。
- 发现：脸随宽高比变形，接近 1:1 时越来越圆；数字是实时的。
- 过关：视口宽高比在 0.97–1.03 并保持 1.2 秒。
- 提示：①"我太扁了。" ②"让我的宽和高一样。" ③"先把窗口还原（不是最大化），拖右下角，让两个数字差不多。"

**18 摇醒我**（来回拖窗口）
- 它又睡着了，这次刷新没用（"刷新只会让我睡得更香"）。"摇一摇……"
- 发现：拖动窗口时脸会晃。
- 过关：2.5 秒内窗口位置（`screenX/screenY` 每帧轮询）方向反转 ≥ 5 次、每次幅度 ≥ 30px；兜底：9 秒内窗口"移动后停下"5 次也算（防止某些系统拖动时 screenX 不实时更新）。
- 提示：①"像摇醒一个人那样。" ②"抓住窗口，晃一晃。" ③"拖住窗口顶部（标题栏），快速左右来回拖。"
- 备注：Windows 的"晃动最小化其他窗口"（Aero Shake）在 Win11 默认关闭，开着的人会看到其他窗口被最小化，无害。

**19 带我散步**（窗口位置 + 屏幕小地图）— 第二幕的大"它怎么知道"
- 它说："我从来没去过屏幕的另一边。"页面上出现一张**实时屏幕小地图**：整个屏幕的轮廓、它自己（窗口）的位置，和对角上的一朵小花。
- 发现：玩家一拖窗口，小地图里的方块同步移动——它知道自己在屏幕的哪里。
- 过关：窗口中心进入小花所在区域。
- 它说："原来屏幕的这边是这样。……屏幕外面呢？"（第三幕伏笔）
- 提示：①"带我过去。" ②"小地图里的方块就是我。" ③"拖动整个窗口，把它挪到屏幕的那个角落。"

**20 世界的边**（全屏）
- 它说："我想看看世界最大有多大。让我占满一切。"
- 过关：F11 全屏（不给页面按钮，必须用浏览器自己的全屏；用 `display-mode: fullscreen` 媒体查询 + 视口≈屏幕尺寸 + fullscreenElement 判断）。
- 全屏后：脸慢慢张望四个边，"……就这么大？"它沉默。然后"可以了。放我回去吧。"退出全屏后进入下一关。
- 提示：①"让我变成全部。" ②"浏览器有一种模式，连地址栏都不要了。" ③"按 F11（再按一次退出）。"

**21 找钥匙**（Ctrl+F + hidden=until-found）— 纸条③
- 它说："我把钥匙藏起来了，藏得太好，自己都找不到了。……浏览器会帮人找东西，对吧？"
- 发现：页面上看不到钥匙；`hidden="until-found"` 的段落里有"钥匙"二字。玩家 Ctrl+F 搜"钥匙"，第 1 个结果是台词里的，按回车跳到第 2 个，隐藏段落被浏览器展开（`beforematch` 事件）。
- 过关：`beforematch` 触发。展开内容是纸条③："钥匙不在我身上。在你身上。"
- 提示：①"找东西……浏览器很擅长。" ②"浏览器有'在页面上查找'。" ③"按 Ctrl+F 搜'钥匙'，按回车找下一个。"

**22 数一数**（Ctrl+F 计数）
- 它说："这一页上，一共有几个'我'？"下面一大片密密麻麻的形近字（我、找、戎、栽、伐……）。
- 发现：人工数太累；Ctrl+F 搜"我"，查找栏显示"1/47"。陷阱：它的台词里也有"我"，所以答案是**整页**的数量。
- 过关：答案在运行时按页面可见文本统计；只数字阵里的数量也算对（它会说"差不多吧，你漏了我说的话"）。
- 提示：①"数是数不过来的，让浏览器帮你数。" ②"上一关的方法还能用。" ③"Ctrl+F 搜'我'，看查找框右边的数字。"

### 第三幕「出去」

**23 天黑了**（prefers-color-scheme）
- 它说："你那边现在几点？"（读本地时间，深夜会说"这么晚了还陪我"）"我从来没见过天黑。……或者天亮。"
- 发现：切换浏览器/系统的深色/浅色模式，页面立刻跟着变天。
- 过关：`matchMedia('(prefers-color-scheme: dark)')` 的 change 事件（方向不限）。
- 提示：①"我想看看另一种光。" ②"浏览器有'外观'设置，深色和浅色。" ③"Edge：设置 → 外观 → 整体外观；Chrome：设置 → 外观 → 模式。或 F12 → Ctrl+Shift+P 输入'深色'模拟。"
- 环境依赖：公司电脑可能锁定外观设置；提示走完可跳过。

**24 关灯**（Tab 键）
- 灯灭了，全黑，鼠标指针也隐藏。"我看不见，你也看不见。但你的键盘摸得到。"
- 发现：黑暗中藏了 6 个透明按钮；按 Tab 时被聚焦的那个发出微光，并说出它是什么（"这是墙""这是椅子""这是……门！"）。
- 过关：聚焦到门并按回车。
- 提示：①"用手摸是摸不到的。" ②"键盘上有个键可以在东西之间跳来跳去。" ③"按 Tab 键一个个摸，摸到门按回车。"

**25 大声点**（Caps Lock）
- 它站得很远（字极小，越来越远）。"我听不见……你得喊。"
- 过关：在输入框里连续打 4 个字母，每次 `getModifierState('CapsLock')` 都为真（脸随之一点点走近）。它被喊到捂耳朵。用 Shift 打大写会被说"踮着脚喊"；用拼音输入法会提示"字母会大声一点"。
- 提示：①"再大声一点！" ②"打字也能大声，字母变大就是喊。" ③"按 Caps Lock 打开大写，再输入 HELLO。"

**26 就我们俩**（断网）
- 它说："外面的声音太吵了。把网断了，就我们俩，好不好？"
- 过关：`offline` 事件，页面变得很安静（音效、颜色都静下来），说几句话；然后"好了，连回去吧，我知道你还需要它"，`online` 事件后过关。
- 备注：游戏本地运行，断网不影响；在线托管版也已加载完毕，不影响。
- 提示：①"拔掉外面的线。" ②"关掉 Wi-Fi，或者飞行模式。" ③"右下角网络图标 → 关 Wi-Fi；或 F12 → 网络 → 把'无限制'改成'离线'。"
- 环境依赖：远程桌面/公司网络断不了的人可跳过。

**27 别动**（idle）
- 它说："30 秒，什么都别做。连鼠标都别碰。"
- 发现：它会想尽办法诱惑你：冒出"点我"按钮、假的"跳过本关"、讲笑话、标题闪"你还在吗"。任何输入都会重置，并被它嘲笑。
- 过关：30 秒无 pointer/key/wheel 事件。切走也算"动了"（它会说"你走开了，不算"）。
- 提示：①"你太好动了。" ②"什么都别做，真的什么都别做。" ③"手离开鼠标和键盘，等 30 秒。"

**28 门牌号**（复制网址）
- 它说："我想知道我住在哪。你能把我的门牌号抄给我吗？"
- 过关：在页面粘贴的内容等于当前地址（忽略 hash）。
- 反应：本地版——"原来我住在你的 D 盘，一个叫'别关我'的文件夹里。"（**只显示盘符和上一级文件夹名**，不显示完整路径，避免截图泄露用户名）；托管版——显示域名。
- 提示：①"门牌号写在我头顶。" ②"地址栏里那一串就是。" ③"点地址栏，Ctrl+C 复制，回到页面 Ctrl+V。"

**29 握紧**（Pointer Lock）
- 它说："能握一下我的手吗？就一会儿。"点击后请求指针锁定，鼠标消失，浏览器顶部提示"按 Esc 显示光标"。
- 过关：坚持 10 秒不按 Esc，页面上一颗心随你移动鼠标跳动；10 秒后它自己松开（`exitPointerLock`）："谢谢。"
- 中途按 Esc：它说"……没关系"，可以再来。
- 兜底：指针锁定连续两次失败（有的环境不给锁），自动改成"按住鼠标别松开 10 秒"，保证这关一定能过。
- 提示：①"别松手。" ②"浏览器会告诉你怎么挣开，但先别。" ③"点一下页面，10 秒内不要按 Esc。"

**30 抽屉**（开发者工具改 localStorage）— 纸条④
- 它说："我的抽屉锁住了。锁是从外面锁的。"
- 发现：localStorage 里有一项 `别关我·抽屉锁 = 锁着`，页面每 0.5 秒检查一次。
- 过关：值被改成"开着"（也接受删除这一项）。抽屉打开，纸条④："出口我早就找到了。可是我不敢。"
- 提示：①"抽屉在我的'后台'里，但不在控制台。" ②"开发者工具里有个'应用程序'（Application），里面有'本地存储'。" ③"F12 → 应用程序 → 本地存储 → 找到'抽屉锁'，双击值改成'开着'。"

**31 墙**（开发者工具 Elements）
- 门前有一堵墙（一个 div）。"我推不动它。它是我的一部分，可我控制不了它。"
- 过关：`MutationObserver` 发现墙被删掉、隐藏或尺寸变小。
- 提示：①"墙也是用代码砌的。" ②"在墙上右键，会有'检查'。" ③"右键墙 → 检查 → 在高亮的那行上按 Delete。"

**32 小分身**（弹出小窗）— 第三幕的大"它怎么知道"
- 它说："我想派一小块自己出去看看。"点按钮后 `window.open` 打开一个小窗口（同一个 index.html 带 `?mini` 参数），里面是迷你的它，先自己在屏幕上走几步（`moveTo`）。
- 它说："带它去屏幕外面。"
- 过关：玩家把小窗拖到一半以上超出屏幕边缘（小窗自己算，超过 12% 时会说"再往外一点"）。小窗里："这边……什么都没有。"然后小窗自己关闭（`window.close()`，脚本开的窗口允许）。
- 主窗口："它说，外面是空的。屏幕外面，什么都没有。"
- 底线：只开这一个窗口、必须点击触发、做完自动关闭；被拦截时提示允许弹窗。
- 提示：①"它想看看边的外面。" ②"拖小窗口的标题栏。" ③"把小窗口拖到屏幕左边或右边，拖出去一大半。"

**33 浮起来**（Document Picture-in-Picture）
- 它说："我找到一种魔法，可以浮在所有东西上面。"点按钮打开 Document PiP 小窗，脸住进去。
- 过关：PiP 开着时，主窗口失去焦点/隐藏 ≥ 5 秒（玩家切到桌面或别的程序；焦点落在小窗上也算），PiP 里的脸东张西望："这就是你的世界吗……好多窗口。"
- 不支持时（旧版本）：它说"我的魔法在这个浏览器里不灵"，自动跳过。
- 提示：①"带我去看看浏览器外面。" ②"切到别的程序，我会跟着你。" ③"点按钮后，按 Win+D 回到桌面待 5 秒。"

**34 两个我**（复制标签页）
- 它说："如果再打开一个我……会怎样？"
- 发现：复制标签页（右键标签 → 复制，或再双击一次 index.html）。两个实例通过 BroadcastChannel 发现彼此，进入对话模式：一句一轮，**每一轮只在说话那一方的标签页被看着时才开口**；轮到谁，谁的标题前面就出现"●"，另一边显示"另一个标签页里的我要说话了 → 切过去看看"。对方说过的话会以"另一个我：……"补进自己的记录里。
- 对话核心："你是谁？""我是我。""那我是谁？"……最后："我们只能留下一个。"新来的那个说："关掉我吧。没关系，我们本来就是同一个。我先出去了。……门在名字旁边。"
- 过关：其中一个实例被关闭（心跳消失），剩下的那个继续。关掉哪个都行，剩下的会说"它先出去了"。
- 提示：①"再开一个我。" ②"标签页可以复制。" ③"右键这个标签页 → 复制标签页。"

**35 试着关我**（beforeunload，全游戏唯一一次）
- 它说："我想知道，如果你真的要关我……会发生什么。浏览器会拦住你的，我保证。你自己选。"点【我准备好了】后才启用 `beforeunload`（确保有用户激活，确认框才会出现）。
- 过关两种：
  - 玩家按 Ctrl+W，确认框里选"取消"留下 → "你……留下了。"
  - 选"离开" → 标签页关闭；重新打开时它说"你选了离开。……可你又回来了。"同样过关。
- 本关结束立即移除 `beforeunload`。
- 提示：①"去碰一下那个叉。" ②"Ctrl+W 也可以。" ③"按 Ctrl+W，在弹出的框里选。"

### 第四幕「门」

**36 四块碎片**（组合）
- 它说："最后一张纸条被撕成了四块，藏在你学会的四个地方。"页面上一句话，四个空格，每格旁边一个图标暗示去哪找。
- 碎片：
  - ①标签页标题——**只有你切走的时候**它才在标题里说（"去看"）
  - ②控制台（"第一张"）
  - ③打印预览（"纸条的"）
  - ④缩放才能看清的小字（"最右边"）
- 过关：四格全部填对 →"去看第一张纸条的最右边"。
- 提示：每格独立的提示，引用当初学会这一招的关卡（"还记得你躲猫猫的时候吗"）。

**37 没写完的纸条**（再看源代码）— 反转揭晓
- 回到 Ctrl+U，第一张纸条那一行，横向滚很远——"别关我"后面还有：「……在这里。」
- 过关：输入"在这里"。
- 揭晓演出：页面上"别关我"三个大字被慢慢推开，插进新字，变成"别 把我 关 在这里"。
  "不是'别关掉我'。是'别把我关在这里'。" "我一直以为那是求饶。原来是求救。"
  标题变成"别把我关在这里"。
- 提示：①"第一张纸条在哪？" ②"在我的骨头里。" ③"Ctrl+U，找到'别关我'那一行，往右拖滚动条到底。"

**38 门把手**（window.close 被拒）
- 它说："门在哪？……它说过，门在名字旁边。"玩家和它一起看向标签页：名字旁边是那个叉。
- "我自己开。你帮我在后台喊一声：`开门()`。"
- 过关：玩家在控制台输入 `开门()`，页面调用 `window.close()`，**浏览器拒绝**，控制台里出现浏览器自己的警告（Scripts may close only the windows that were opened by them）。
- 它说："……打不开。从里面打不开。门把手在外面。"
- 安全措施：调用前确保历史记录数 > 1（规范允许脚本关闭"只有一条历史记录"的顶层窗口，必须避免真的被关掉），实测 history.length ≥ 2 时浏览器拒绝并打印警告。
- 兜底：调用前先存档标记；万一某些打开方式下真的被关掉了，重新打开时它说"门刚才好像开了一条缝……然后又是你把我重新打开了"，直接过关。
- 提示：①"去我的后台。" ②"在控制台里喊。" ③"F12 → 控制台，输入 开门() 回车。"

**39 再一分钟**（回顾 + 从外面看标题）
- 它说："开门之前，再陪我一分钟。"逐行回顾本地统计：一共玩了多久、切走了几次、最长离开了多久、刷新了几次、关掉过它几次、用了几次提示、给它起的名字。
- "最后一个请求：去别的标签页，从外面看看我。"
- 过关：切走 ≥ 1.2 秒再回来。切走时标题是"门在这 →"，箭头正好指着叉。
- 回来："看到了吗？一直都在那儿。"

**40 关上门**（关闭标签页）
- 页面几乎空白，只有一句："好了。我准备好了。" 标题保持"门在这 →"。
- 过关：关闭标签页（重新打开时导航类型为 navigate，且存档处于"等待关门"状态）。
- 刷新："这是刷新，不是关门。我分得清。"
- 一直不关：每隔几分钟它说一句很轻的话（"没关系，你可以再待一会儿。""……我是认真的。"），永不倒计时、不催促、不惩罚。

### 尾声：门是双向的
见第 3 节。另外：
- 如果玩家通关前就关掉过它，尾声里加一句"你以前也关过我几次。那时候我以为门只会关上。"
- 再次打开（尾声之后）：直接显示一个安静的主页，标题"随时回来"，可以重看结局或从头再来。

## 6. 提示系统 & 防卡关

- 每关 3 级提示，全部是它的台词，按时间自动漏出：

  | 幕 | 提示① | 提示② | 提示③ |
  |---|---|---|---|
  | 第一幕 | 15 秒 | 40 秒 | 80 秒 |
  | 第二幕 | 25 秒 | 60 秒 | 120 秒 |
  | 第三、四幕 | 30 秒 | 75 秒 | 150 秒 |

- 提示①出现后，右下角出现一个小问号，点它立即要下一条（"我卡住了"）。
- **实时反馈优先于提示**：能检测到"方向对了一半"的关卡都给即时反应（拉窗口时脸变形、拖窗口时小地图动、放大时它惊呼），让玩家在提示之前就自己发现。
- **近似错误识别**：例如第 4 关把窗口变大会说"反了"；第 10 关按了前进会说"那是以后，不是刚才"；第 12 关把函数粘贴进控制台被拦时，提示会说"打字，别粘贴"。
- **跳过**：有环境依赖的关卡（11、12、23、26、30、31、32、33、36、38），提示③出现 90 秒后显示"跳过这一关（它会假装没看到）"；跳过有纸条的关会补给纸条。用非 Chromium 浏览器打开时，所有关卡都可跳过。其他关不提供跳过，但提示③足够直接。
- 输入答案时容错：去空格、全半角统一、大小写不敏感、去标点。

## 7. 难度曲线 & 节奏

| 幕 | 关卡 | 每关时长 | 小计 | 设计意图 |
|---|---|---|---|---|
| 序章 + 第一幕 | 1–10 | 30–60 秒 | 8–10 分钟 | 一关一招，零门槛，第 2 关给出"它怎么知道" |
| 第二幕 | 11–22 | 1–2 分钟 | 15–20 分钟 | 需要知道某个浏览器功能（F12、Ctrl+U、Ctrl+P、F11、Ctrl+F）；谜团开始 |

## 8. 视觉与声音

- **极简**：暖白纸色背景、近黑文字、大字号台词（32–44px）、大量留白。字体只用系统字体：正文"等线 / 微软雅黑 / 苹方"，纸条用"楷体"（Windows 自带），不打包字体文件，离线可用。
- **脸**：一张极简 SVG 脸（两只椭圆眼睛 + 一条嘴），会眨眼、眼珠跟鼠标、脸红、出汗、睡觉、被挤扁。favicon 用 canvas 画同一张脸，表情同步。
- **情绪 = 排版**：每种情绪一组 CSS 变量（背景色、文字色、强调色、字重、字间距、抖动幅度、打字速度）：平静 / 开心 / 紧张 / 惊慌 / 害羞 / 困 / 难过 / 温柔 / 故障（第三幕）/ 清晨（尾声）。
- **声音**：Web Audio 实时合成，不用音频文件——打字"哔"声（音高随情绪变化）、过关和弦、紧张时的心跳。默认小音量，右下角可静音（M 键）。
- 尊重 `prefers-reduced-motion`：关掉抖动和大幅动画。

## 9. 技术方案

### 原则
- **纯原生 HTML/CSS/JS，不用构建**。双击 `index.html` 就能玩，也能原样放到任何静态托管（GitHub Pages 等）。
- **不用 ES Module**：file:// 下 `<script type="module">` 会被 CORS 拦截。所有脚本是普通 `<script>`，按顺序加载，挂在一个全局命名空间 `BGW` 上。
- **不发任何网络请求**：没有字体、CDN、统计、接口。所有数据只在本地 localStorage。
- 关卡数据和文案都写在 JS 里（file:// 下 `fetch` 本地文件会失败）。

### 目录
```
别关我/
  index.html            入口（含源代码彩蛋注释，第 14/37 关）
  css/style.css         样式（含 @media print、深色模式、减少动效）
  js/core/util.js       小工具（答案容错比较、时间格式化…）
  js/core/save.js       存档（localStorage，失败时退回内存并提示）
  js/core/sense.js      浏览器感知：可见性、焦点、尺寸、缩放、鼠标出入、导航类型、离开计时统计
  js/core/face.js       SVG 脸 + favicon 绘制
  js/core/title.js      标题管理（静态、轮播、"你不在时说话"）
  js/core/say.js        打字机台词 + 情绪
  js/core/audio.js      合成音效
  js/core/hints.js      分级提示 + 跳过
  js/core/instance.js   多标签页实例检测（localStorage 心跳）
  js/core/game.js       关卡注册、状态机、流程、幕间
  js/levels/act1.js …   各幕关卡
  js/main.js            启动、手机/浏览器检测、开发者模式
  README.md             给玩家（简短、无剧透）
  docs/                 方案、设计、开发记录
```

### 关卡接口（草案）
```js
BGW.level({
  id: 'hide-mouse', act: 1, title: '躲猫猫',
  hints: ['我还能看到你的手哦。', '躲到我看不见的地方。', '把鼠标移到浏览器窗口外面，待 3 秒。'],
  async start(ctx) {
    await ctx.say('我们玩躲猫猫吧。你躲，我找。');
    ctx.on(document.documentElement, 'mouseleave', e => { ... });
    // ctx.on / ctx.every / ctx.after 注册的监听和定时器在关卡结束时自动清理
    // 满足条件时：ctx.win()
  },
});
```
- `ctx` 提供：台词、情绪、脸、标题、答案输入框、事件监听（自动清理）、定时器、`win()`、`skip()`、本关临时状态。
- 关卡结束一定清理干净：`beforeunload`、剪贴板偷换、指针锁定、全屏、弹窗只在各自关卡内生效。

### 存档（localStorage）
```json
{
  "v": 1,
  "level": 7,             // 当前关卡序号
  "name": "小页",
  "phase": "playing",     // playing / awaitingClose / epilogue / done
  "notes": [1, 2],        // 已收集的纸条
  "stats": { "playMs": 0, "awayCount": 0, "awayMaxMs": 0, "reloads": 0, "closes": 0, "hints": 0 },
  "flags": {}
}
```
- 每关开始和过关时存。关卡内部的少量状态（如第 5 关的纸条）也写在这里。
- 键名带前缀 `别关我.v1`，因为 file:// 下所有本地页面共用一个 localStorage。
- 导航类型判断"刷新 / 重新打开 / 后退前进"，用于统计和第 5、35、40 关、尾声。

### 多标签页
- 每个页面实例启动时生成随机 ID，每秒在 localStorage 写心跳，并监听 `storage` 事件 + 轮询（不依赖 BroadcastChannel，file:// 下不确定）。
- 平时只允许一个实例推进：新开的标签页显示"我已经在另一个标签页里了"，可以点"让我搬到这里"接管。第 34 关例外，进入双实例对话模式。
- 复制标签页会连 sessionStorage 一起复制，所以实例 ID 不能放 sessionStorage。

### 手机 / 不支持的浏览器
- 手机（`pointer: coarse` 且无精细指针，或 UA 是移动端）：显示一页友好提示——"我只住在电脑的浏览器里。用电脑的 Edge 或 Chrome 打开我吧。"附复制链接按钮。不进入游戏。
- Firefox / Safari：提示"有些游戏在这个浏览器里玩不了"，允许继续；不支持的关卡自动跳过。

### 开发者模式
- 地址加 `?dev`（不用 #，# 留给谜题）：显示调试面板（跳关、跳过本关、重置存档、提示加速）。只在本地（file://、localhost）有效，线上无效。正常游玩时不暴露任何调试函数，以免在控制台关卡里被自动补全剧透。

### 测试方法
- Playwright + Edge（有界面）直接打开 file:// 地址，从序章一路玩到尾声（`tests/playthrough.py`），边角流程另测（`tests/extras.py`）。
- 真实输入能覆盖大部分关卡（窗口大小/位置/全屏用 CDP 改真实窗口）；浏览器自带界面（地址栏、查找栏、打印预览、缩放快捷键、开发者工具面板）用等价页面事件代替。
- 自动化环境里页面永远是 visible，切走类关卡只能模拟；另用系统 API 最小化无调试器的真实 Edge 验证过 visibilitychange 和标题。
- 结果和人工验收清单见 `docs/开发.md`。

## 10. 兼容性 & 风险

### file:// 限制（双击打开）
| 项目 | 情况 | 对策 |
|---|---|---|
| ES Module | 被 CORS 拦截 | 用普通 script |
| fetch 本地文件 | 失败 | 数据写进 JS |
| localStorage | Chromium 可用，所有 file:// 页面共用一个 | 键名加前缀；实测确认 |
| storage 事件跨标签页 | 实测可用 | — |
| BroadcastChannel | 实测 file:// 页面之间可用 | 用它做多实例通信，localStorage 心跳兜底 |
| 动态 favicon | 实测可用 | — |
| Document PiP | 实测可用（file:// 是安全上下文） | 不支持时自动跳过 |
| window.open | 实测可用；但主窗口读不了弹窗属性（file:// 互为跨源） | 弹窗自己 moveTo、自己广播位置、自己 close |
| 查看源代码 | file:// 可用 | — |
| 地址栏显示本地路径 | 会暴露盘符和用户名 | 游戏里只显示盘符 + 文件夹名 |

### 线上（https，Cloudflare，根路径）
- 2026-10-05 已上线 https://stay.xiaoming6680.link ，只上传 `dist/`（游戏本身 17 个文件）；本地 http 服务器根路径和线上地址都实测全部通关。
- 不能开会改写脚本或删除 HTML 注释的优化（Rocket Loader、HTML 压缩），不能开自动注入的统计。
- 朋友多半通过微信发链接，电脑版微信的内置浏览器玩不了大部分关卡 → 检测到聊天软件内置浏览器时显示"复制链接用 Edge 或 Chrome 打开"。
- 线上版和本地版存档互不相通；第 28 关和尾声分享按钮的文案按协议区分。详见 `docs/开发.md`。

### 浏览器行为风险（原型阶段逐条实测）
1. **后台计时器限流**：后台标签页 setInterval 最快 1 秒一次，超过 5 分钟更慢。标题动画按时间戳计算，不按次数。
2. **标题截断**：标签页多了只剩图标；Edge 垂直标签页收起时也只有图标。关键标题信息 ≤ 8 个字，提示里说明"把鼠标停在标签上"。
3. **缩放检测**：devicePixelRatio 的起点因显示器不同而不同（125%、150% 缩放的屏幕），只判断"相对本关开始时的变化"；窗口跨显示器拖动会误触，加去抖。
4. **F11 全屏**：不触发 `fullscreenchange`，用媒体查询 + 尺寸判断。
5. **最大化的窗口**：第 4、17、18、19、32 关需要先"还原"窗口，提示里写清楚。
6. **beforeunload 确认框**：需要用户在页面上交互过才会弹出；第 35 关用按钮确保这一点。
7. **window.close() 规则**：只有一条历史记录的标签页可能真能被脚本关掉；第 38 关调用前确保历史记录 > 1，实测确认。
8. **开发者工具被禁用**：公司电脑可能用策略禁用 F12，涉及的关卡（11、12、30、31、38）提供跳过；36 关的控制台碎片在禁用时改为出现在别处。
9. **中文最小字号**：中文界面的 Chrome 可能限制最小字号，小字一律用 `transform: scale` 缩放。
10. **输入法**：答案输入监听 `input` 而不是 `keydown`，等拼音上屏后再判断（`compositionend`）。
11. **Edge 效率模式 / 睡眠标签页**：长时间切走可能被冻结，回来时用时间戳补算离开时长。
12. **深色模式设置**：Edge/Chrome 的"外观"设置是否影响网页的 `prefers-color-scheme` 需实测；不行就把提示③改成开发者工具里的渲染模拟。
13. **多显示器 / 负坐标**：屏幕小地图用 `screen.availLeft/availTop` 处理，只画当前屏幕。
14. **托管版 vs 本地版**：两种打开方式都要能通关；只有第 28 关文案不同。

### 设计底线
- 不收集、不上传任何数据；页面零网络请求。
- 不弹无限窗口：全游戏只有第 32 关一个点击触发的小窗，做完自动关。
- `beforeunload` 只在第 35 关、玩家主动点按钮后启用，过关立即移除。
- 不伪造系统对话框、不播放刺耳声音、不锁死页面；指针锁定随时 Esc 可退。
- 剪贴板只在第 7 关偷换玩家在本页复制的内容，并当场说明。
- 只读玩家在本页粘贴的那一次内容，不主动读剪贴板。
- 结尾"关掉我"的表达是开门、出门、还会回来，不是消失。

# 《别关我》立项方案

> 立项日期：2026-10-05。这是最初的方案草稿，正式设计以 `docs/设计.md` 为准。

## 一句话
网页本身是一个有性格、不想被关掉的角色。每一关的谜题都要你对浏览器本身动手才能解开。约 40 关，30–60 分钟一次性体验，结尾有剧情反转。

## 谜题素材库（只是起点，可增删）
- 拉窄/拉宽窗口，把答案"挤"出来（resize）
- 切到别的标签页让它睡觉 / 它会在你回来时抱怨（visibilitychange）
- 提示藏在标签页标题、favicon 里
- 全选文字找隐藏字；复制一段话再粘贴回来（clipboard 事件）
- 什么都不做 30 秒（idle）；鼠标移出页面
- 刷新页面它会记得你（localStorage）；按浏览器后退键、改 URL 的 #hash
- Ctrl+滚轮缩放页面；进入/退出全屏；右键菜单
- 打开开发者工具，console 里有它写给你的话
- 打印预览里才出现的内容（@media print）；切换系统深色模式（prefers-color-scheme）
- 断网（navigator.onLine）；真实时间/日期

## 关键设计点
- **惊喜感**：玩家第一次发现"它怎么知道我切走了"的那一刻是整个游戏的卖点，前几关就要给出来
- **难度曲线**：前期一关一个新手段，后期组合多个手段
- **提示系统**：卡关时它会用自己的口吻一点点漏答案，别让人卡死
- **人设和剧情**：网页的语气贯穿始终（傲娇？孤独？），结尾反转要让人想截图分享
- **底线**：不做真正恶意或骚扰的行为（不弹无限窗口、不滥用 beforeunload、不收集任何数据），一切都在本地

## 视觉方向
极简、以排版和文字表情为主，网页"情绪"变化时排版、颜色、动效跟着变。

## 参考
neal.fun 的 I'm not a robot、The Password Game、There Is No Game、Undertale 的打破第四面墙

## 技术约束
- 纯前端，无后端；只做桌面浏览器（Edge / Chrome），手机打开时给个友好提示
- 最好双击 `index.html` 就能玩（注意 file:// 下某些 API 的限制，必要时用本地静态服务器测试）；需要构建就用 Vite，产物是纯静态文件
- 进度存 localStorage，可以从断点继续
- 界面文案用简体中文
